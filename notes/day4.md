# Day 4: Engineering Foundation

## Concepts Learned

* **Virtual Environment:** An isolated Python environment that bundles project-specific dependencies separately from the system Python installation to avoid version conflicts.
* **pytest:** A testing framework used to write and run automated unit tests efficiently.
* **Ruff:** An extremely fast Python linter and code formatter that checks code quality and enforces formatting rules.
* **CI (Continuous Integration):** An automated practice where code changes are built and tested automatically upon pushing to the repository to catch bugs early.
* **YAML `on`:** A configuration keyword that defines the specific git events (like a push or pull request) that trigger a workflow execution.
* **`runs-on`:** A workflow directive that specifies the type of hosted virtual machine runner (e.g., Ubuntu Linux) that will execute the job.
* **`steps`:** An ordered sequence of individual shell commands or actions executed sequentially within a CI workflow job.
